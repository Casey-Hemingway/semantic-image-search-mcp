## Project Overview

This is an MCP (Model Context Protocol) server that provides semantic image search capabilities over a photo archive using AI-powered image understanding.

## Key Information

- The server indexes photos from the configured library path
- Search uses natural language queries to find images based on visual content
- Images can be filtered by date, folder patterns, and other metadata
